# 可维护性、可读性、命名审查规则

本规则用于审查命名规范、代码可读性、注释规约、可维护性（单一职责、兼容演进）、控制语句、项目/用户规则合规等可维护性与可读性问题。

优先级定义和通用审查执行指引见 `common-review-guide.md`。

---

## 一、命名规范

### 1.1 命名风格

| 规则编号 | 所属分类 | 检查对象 | 判定标准 | 严重等级 | 整改指引 |
|----------|----------|----------|----------|----------|----------|
| 1.1.1 | 代码规范 | 类名 | 未使用大驼峰 UpperCamelCase（如 `userService`、`order_info`） | P2 | 改为大驼峰：`UserService`、`OrderInfo` |
| 1.1.2 | 代码规范 | 方法名/变量名/参数名 | 未使用小驼峰 lowerCamelCase（如 `UserName`、`GetUser`） | P2 | 改为小驼峰：`userName`、`getUser` |
| 1.1.3 | 代码规范 | 常量 | 未使用全大写+下划线分隔（如 `maxCount`、`base_url`） | P2 | 改为 `MAX_COUNT`、`BASE_URL` |
| 1.1.4 | 代码规范 | 抽象类名 | 未以 `Abstract` 或 `Base` 开头 | P2 | 重命名为 `AbstractXxx` 或 `BaseXxx` |
| 1.1.5 | 代码规范 | 异常类名 | 未以 `Exception` 结尾 | P2 | 重命名为 `XxxException` |
| 1.1.6 | 代码规范 | 测试类名 | 未以被测类名+`Test` 结尾 | P2 | 重命名为 `XxxTest` |
| 1.1.7 | 代码规范 | 包名 | 含大写字母或下划线（如 `com.example.User_Util`） | P2 | 改为全小写无下划线：`com.example.user.util` |
| 1.1.8 | 代码规范 | 布尔变量 | 未以 `is`/`has`/`can`/`should` 前缀；POJO 中 `isXxx` 与属性冲突 | P2 | 添加布尔前缀，POJO 布尔字段禁止使用 `is` 前缀以免与 getter 冲突 |
| 1.1.9 | 代码规范 | 接口实现类 | 未以 `Impl` 结尾 | P2 | 重命名为 `XxxImpl` |
| 1.1.10 | 代码规范 | 命名语义 | 使用拼音缩写或无意义变量名（如 `a1`、`str1`、`zhiFu`） | P2 | 替换为有语义的英文命名 |

## 二、可读性

### 2.1 代码可读性

| 规则编号 | 所属分类 | 检查对象 | 判定标准 | 严重等级 | 整改指引 |
|----------|----------|----------|----------|----------|----------|
| 2.1.1 | 代码规范 | 条件嵌套深度 | `if/else if/else` 嵌套超过 3 层 | P1 | 通过提前返回、抽取方法或策略模式简化 |
| 2.1.2 | 代码规范 | 条件表达式复杂度 | 条件表达式超过 3 个逻辑运算符 | P1 | 抽取为布尔变量或判断方法 |
| 2.1.3 | 代码规范 | 方法长度 | 单个方法体超过 80 行 | P1 | 拆分为多个职责单一的小方法 |
| 2.1.4 | 代码规范 | 字符串判空 | 使用 `str == ""` 或 `str.equals("")` 判空 | P1 | 改用 `StringUtils.isBlank(str)` 或 `str.isEmpty()` |

## 三、注释规约

### 3.1 注释

| 规则编号 | 所属分类 | 检查对象 | 判定标准 | 严重等级 | 整改指引 |
|----------|----------|----------|----------|----------|----------|
| 3.1.1 | 代码规范 | 核心注释 | 类、public 方法、复杂逻辑缺少 JavaDoc 或清晰注释 | P2 | 补充 JavaDoc，说明参数、返回值、关键逻辑 |
| 3.1.2 | 代码规范 | 注释一致性 | 注释与代码逻辑不一致，修改代码后未同步更新注释 | P2 | 同步更新注释 |
| 3.1.3 | 代码规范 | TODO/FIXME | `// TODO`/`// FIXME` 标记长期遗留无跟进计划 | P2 | 添加跟进计划或及时处理 |
| 3.1.4 | 代码规范 | 调试代码 | 注释中遗留调试代码 | P2 | 删除调试代码 |
| 3.1.5 | 代码规范 | 注释掉的代码 | 存在注释掉的代码 | P2 | 删除无意义冗余代码 |
| 3.1.6 | 代码规范 | 注释解释原因 | 注释仅解释代码做什么而非为什么这么做 | P2 | 注释须解释为什么，而非代码做什么 |
