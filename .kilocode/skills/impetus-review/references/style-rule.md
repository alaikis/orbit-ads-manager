# 风格与格式审查规则

本规则用于审查常量与魔法值、格式与缩进、OOP 规约、集合处理、日志规范、版权声明等风格与格式问题。

优先级定义和通用审查执行指引见 `common-review-guide.md`。

---

## 一、常量与魔法值

### 1.1 常量定义

| 规则编号 | 所属分类 | 检查对象 | 判定标准 | 严重等级 | 整改指引 |
|----------|----------|----------|----------|----------|----------|
| 1.1.1 | 代码规范 | 魔法值 | 代码中直接出现未解释的字面量 | P2 | 抽取为命名常量并统一管理 |
| 1.1.2 | 代码规范 | 常量分类 | 常量未按功能分类维护，存在重复定义或含义冲突 | P2 | 按功能分组到不同常量类 |
| 1.1.3 | 代码规范 | 跨应用常量 | 跨应用共享常量未通过常量类或接口统一管理 | P2 | 抽取到共享常量类/接口 |
| 1.1.4 | 代码规范 | 常量命名风格 | 同一常量类中命名风格不一致 | P2 | 统一为全大写+下划线分隔 |
| 1.1.5 | 代码规范 | 硬编码配置 | 配置项硬编码在代码中 | P2 | 抽取到配置中心（Apollo/SpringCloud Config） |

## 二、格式与缩进

### 2.1 代码格式

| 规则编号 | 所属分类 | 检查对象 | 判定标准 | 严重等级 | 整改指引 |
|----------|----------|----------|----------|----------|----------|
| 2.1.1 | 代码规范 | 大括号换行 | 左大括号换行风格不统一 | P2 | 统一 K&R 风格（左大括号不换行） |
| 2.1.2 | 代码规范 | 单行长度 | 单行字符超过 120，或单行定义多个变量 | P2 | 拆分换行，每行一个变量 |
| 2.1.3 | 代码规范 | 语句大括号 | `if`/`for`/`while` 只有一行时未使用大括号包裹 | P2 | 补充大括号 |
| 2.1.4 | 代码规范 | 运算符空格 | 运算符前后或逗号后未加空格 | P2 | 添加规范空格 |
| 2.1.5 | 代码规范 | 参数换行 | 方法参数列表过长未换行，或换行后缩进不规范 | P2 | 参数换行并对齐缩进 |

## 三、OOP 规约

### 3.1 OOP 规范

| 规则编号 | 所属分类 | 检查对象 | 判定标准 | 严重等级 | 整改指引 |
|----------|----------|----------|----------|----------|----------|
| 3.1.1 | 数据正确性 | POJO 属性类型 | POJO 类属性使用基本类型而非包装类型，无法表达 `null` 语义 | P2 | 改为包装类型（如 `int` → `Integer`） |
| 3.1.2 | 数据正确性 | serialVersionUID | 序列化类未显式声明 `serialVersionUID` | P2 | 添加 `private static final long serialVersionUID = 1L;` |
| 3.1.3 | 代码规范 | 访问修饰符 | 类成员缺少明确访问修饰符或使用不必要的 `public` 字段 | P2 | 设置最小权限访问修饰符，字段用 `private` |
| 3.1.4 | 数据正确性 | equals 常量位置 | `equals` 比较时变量在左、常量在右（如 `str.equals("abc")`） | P2 | 常量置左：`"abc".equals(str)`，避免 NPE |
| 3.1.5 | 数据正确性 | equals 与 hashCode | 重写 `equals` 但未重写 `hashCode` | P2 | 同时重写 `hashCode`，保证 HashMap/HashSet 行为一致 |
| 3.1.6 | 数据正确性 | 对象比较方式 | 使用 `==` 比较对象而非 `equals`（枚举和基本类型除外） | P2 | 改用 `equals` 方法比较 |

## 四、日志规范

### 4.1 日志规范

| 规则编号 | 所属分类 | 检查对象 | 判定标准 | 严重等级 | 整改指引 |
|----------|----------|----------|----------|----------|----------|
| 4.1.1 | 日志与异常 | 日志拼接方式 | 使用字符串拼接打日志：`log.debug("result: " + obj)` | P2 | 改用 slf4j 占位符：`log.debug("result: {}", obj)` |
| 4.1.2 | 日志与异常 | error 日志内容 | `error` 日志仅打印 `e.getMessage()` 未打印异常对象 | P2 | 改为 `log.error("msg", e)` 传入异常对象 |
| 4.1.3 | 日志与异常 | System.out | 使用 `System.out.println()`/`System.err.println()` | P2 | 替换为 SLF4J 日志框架 |
| 4.1.4 | 日志与异常 | 日志级别 | 日志分级不合理，调试日志提交到代码库 | P2 | 调整日志级别，删除调试日志 |
| 4.1.5 | 日志与异常 | 核心流程日志 | 核心流程日志缺少链路ID、用户标识、入参、耗时、异常堆栈 | P2 | 补充 MDC 链路ID和关键上下文信息 |
| 4.1.6 | 日志与异常 | Logger 类名 | 日志中类名与实际类不一致（复制代码后未修改 logger） | P2 | 修改 logger 声明或使用 `@Slf4j` 注解 |
