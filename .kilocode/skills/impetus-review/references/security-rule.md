# 安全与风险审查规则

本规则用于审查 SQL 注入、XSS、越权、敏感数据、接口安全、接口防护、安全依赖等安全与风险问题。安全漏洞一票否决。

优先级定义和通用审查执行指引见 `common-review-guide.md`。

## 本轮特有指引

1. **安全优先**：安全漏洞一票否决，发现问题必须报告，不可跳过。

---

### 1.1 SQL 注入防护

| 规则编号 | 所属分类 | 检查对象 | 判定标准 | 严重等级 | 整改指引 |

| 规则编号 | 所属分类 | 检查对象 | 判定标准 | 严重等级 | 整改指引 |

| 3.1.1 | 安全漏洞 | 敏感数据明文存储 | 手机号、身份证、密码等敏感数据明文存储 | P0 | 脱敏或加密存储 |
